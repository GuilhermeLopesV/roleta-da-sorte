# 🎡 Roleta da Sorte

Uma roleta interativa e personalizável feita com HTML, CSS e JavaScript puro.

## ✨ Funcionalidades

- 🎨 Roleta animada com segmentos coloridos
- ✏️ Editor de itens em tempo real
- 🎉 Animação de confete ao sortear
- 📜 Histórico de resultados
- 📱 Layout responsivo

## 🚀 Como usar

Basta abrir o arquivo `index.html` no navegador. Nenhuma instalação necessária!

## 🎮 Itens padrão

A roleta vem configurada com jogos de família:
- 🃏 UNO
- 🔍 Detetive
- 🎲 War
- 🐍 Jogo da Memória
- 🎯 Banco Imobiliário

## 🛠 Tecnologias

- HTML5 + Canvas API
- CSS3 (animações, glassmorphism)
- JavaScript Vanilla
